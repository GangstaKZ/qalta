# Qalta — личный кошелек

PWA для учёта личных расходов (KZT, RU). Без регистрации — всё в localStorage.

## Команды

```bash
npm run dev    # разработка
npm run build  # production-сборка
npm run icons  # перегенерировать PWA-иконки
```

## Возможности

- Быстрое добавление расхода (сумма → категория → сохранить)
- Дашборд: потрачено сегодня / остаток месячного бюджета
- Аналитика: круговая диаграмма по категориям за текущий месяц
- Лента операций с группировкой Сегодня / Вчера / по датам
- Месячный бюджет (спрашивается при первом запуске, меняется в Настройках)
- PWA: manifest + service worker, offline после первого визита
